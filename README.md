# AI 割韭菜套路揭秘

输入一个项目、课程或模式，AI 拆解它的常见割韭菜套路、隐藏成本、信息差，帮你避坑。只做模式分析，不点名、不诽谤。

## 它能帮你做什么

- 看穿引流话术、转化套路、交付缩水、续费陷阱
- 标出"看起来免费实则最贵"的隐藏成本
- 指出哪些公开知识被包装成独门秘籍
- 给 3-5 条可自己验证的避坑动作（查资质、看合同、问退款、搜投诉）

## 怎么用

1. 把你看不懂或心动的项目/课程发过来
2. 说明你最担心的点（钱、时间、被坑）
3. 拿到一份"套路拆解 + 自验动作"清单

## 适合谁

- 想搞副业又怕被割的普通人
- 刷到"日入过万""自动赚钱"广告拿不准的人
- 帮家人把关加盟/培训的中年人

## 合规边界

- 不诽谤特定主体、不传播未证实指控
- 不替代监管、消协、公安等官方渠道
- 所有分析标注"仅供参考"，风险自担
