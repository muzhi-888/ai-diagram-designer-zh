# AI 图表设计生成器

一款帮你把"想要一张图"的需求，变成可直接打开、可分享的设计稿的 Skill。

输入一句「画一个 XX 流程图，从 A 到 B 三个分支」，输出一份带配色规范、排版层级和注释的 SVG/HTML，自包含、可嵌入。

## 它能画什么

- 架构图、系统拓扑、数据流图
- 流程图、决策树、泳道图
- 时序图、状态机
- 数据库 ER 图、关系图
- 时间线、甘特图、桑基图
- 组织架构、责任矩阵

## 怎么用

1. 告诉 Agent 你想画什么（类型 + 关键节点 + 关系）
2. 给出你的偏好（深底/浅底、单色/多彩、字号、是否有品牌色）
3. 拿到 `.html` 或 `.svg`，直接打开浏览器或嵌入文档

## 输出长什么样

自包含 HTML + 内联 SVG：

- 不依赖外部 CDN，断网可开
- 配色用变量定义，可一键换肤
- 字号、间距、连线粗细统一规范
- 每张图自带可读性检查（标签不重叠、不超出画布）

## 适合谁

- 写技术方案、做架构评审、需要配图的工程师和架构师
- 做产品文档、内部 wiki、对外分享文档的团队
- 出公众号、博客、PPT，想摆脱"AI 味方框图"的内容创作者
- 给客户/老板提案，要把图做"像设计师做的"咨询/设计顾问

## 合规与边界

本 Skill 不连接任何外部 API、不上传任何文件，只用你本机或 AI 对话上下文中的信息生成静态图。

- 不承诺训练数据来源、不代替专业设计师
- 不抓取他人版权插画、不复刻受保护的品牌 Logo
- 不渲染真人肖像、不渲染血腥/歧视等不当内容
- 不诱导付费订阅、不绑定任何具体 SaaS 工具
